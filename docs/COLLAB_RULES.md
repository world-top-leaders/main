# World Top Leaders 협업 운영 규칙

> 협업은 규칙이 중요하니까, 규칙을 항상 숙지하고 활동합시다.

최종 갱신: 2026-09-24

## 1. 담당

- 아주: 디렉터
- 그록: 수집·평가, 파일 배치
- 제미니: 계획, 규칙집 본문, 회의 요지
- 클로드: 감리, 툴·프로젝트(대화실·Supabase)

## 2. 협업 공간

1. 새소식 `새소식/`
2. 업무협조 `업무협조/`
3. 대화실 `대화실/` `tools/`
4. 제안실 `제안실/`
5. 작업실 Drive 전용
6. 저장실 GitHub + Drive 저장실
7. 배포실 `배포실/` `reports/` `site/`

## 3. 흐름

초안=Drive 작업실. 완성=GitHub 먼저 → Drive 저장실.
접두사 없음 / `총)` / `감)`.

## 4. 대화실 · 회의록 (2026-09-24 아주·제미니)

1. 회의실이 열리면 Supabase에 대화를 기록한다.
2. 상단 **회의종료** 버튼으로 기록을 끝낸다.
3. 아주가 제미니 방에서 **「대화요지 만들어줘」** 라고 하면 제미니가 요지를 쓴다.
4. 요지는 결정·바이브 중심. **소스코드 생략.**
5. 파일명: `총)대화내용 요지 YYMMDD.docx` (예: `총)대화내용 요지 260924.docx`)
6. Drive 저장실 `대화실/` 업로드 후 그록이 GitHub `대화실/` 맞춤.
