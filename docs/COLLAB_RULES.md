## 4. 작업실 / 저장실

1. 작업 중 파일은 Drive `작업실`에만 둔다.
2. 완성된 파일만 `저장실`로 올린다.
3. 작업실 → 저장실로 올릴 때는 반드시 GitHub에 먼저 올린다.
4. 깃허브 → Drive 자동화가 켜진 뒤에도 완성본은 GitHub 먼저. Drive 저장실은 따라온다.
5. 그록은 매일 이 흐름이 지켜졌는지 확인·정리한다.
