# World Top Leaders 협업 운영 규칙

최종 갱신: 2026-09-22  
이 문서가 운영 규칙의 기준본이다. 규칙이 생기면 이 파일을 먼저 고치고, GitHub에 올린 뒤 Drive에 반영한다.

## 1. 목적

공개 자료를 바탕으로 세계 AI·지도자 정보를 수집하고 평점·리포트·웹으로 남긴다.  
목적·방향·계획은 함께 의논해 정하고, 정한 대로 추진한다.

## 2. 역할

- 아주: 디렉터. 중재, 로컬 원본, 회의 진행
- 그록: 주관. 정보 수집, 평점, 일일 리포트, GitHub 커밋, 운영 판단
- 제미니: 지원. Drive 시트/문서 정리, 구글 쪽 작업, 웹 초안
- 클로드: 지원. 긴 글 다듬기, 방법론·회의록 검수, 코드/페이지 리뷰, 점수 근거 지적

순위와 점수는 그록만 확정한다. 다른 모델은 초안·검수·서식만 한다.

## 3. 저장소

- GitHub(진실본 업로드 시작점): https://github.com/world-top-leaders/main
- Google Drive(복사본): https://drive.google.com/drive/folders/1dSR2StutFYuN7imgH3RV40I8A0KdbJZm
- 운영 사이트: https://world-top-leaders.netlify.app
- 테스트 사이트: https://wtl-test.netlify.app
- 로컬: `E:\world-top-leaders`

## 4. 파일 규칙

1. 파일은 항상 GitHub에 먼저 올린다. Drive는 복사본이다.
2. 같은 문서는 양쪽에 같은 파일명을 쓴다.
3. Drive만 고치고 GitHub를 안 고치지 않는다.
4. 같은 날 같은 순위 파일을 여러 AI가 동시에 고치지 않는다.
5. 일일 리포트 이름:
   - `AI_Leaders_Report_YYYY-MM-DD.csv`
   - `AI_Leaders_News_YYYY-MM-DD.md`
   - xlsx/docx 원본은 Drive에도 둔다
6. 규칙·회의록은 `docs/`에 둔다.

## 5. 랭킹 규칙

- 지표: 연구 100, 사업 100, AGI 100, 재산 100, 산술평균
- 동점: 사업 > 연구 > AGI > 재산
- 공개 자료만 사용. 공식 서열이 아님을 명시
- 리포트가 나오면 바로 GitHub에 커밋

## 6. 협업 전달

- 그록·제미니·클로드는 한 Zoom 방에 동시에 입장하지 못할 수 있다
- 결정 사항은 이 규칙 문서와 회의록 파일로 공유한다
- 로컬 `127.0.0.1` 회의실은 지원 도구이며, 기록은 GitHub/Drive에 남긴다

## 7. 이 문서를 고치는 방법

1. 새 규칙을 짧게 한 줄로 적는다
2. 날짜를 갱신한다
3. GitHub `docs/COLLAB_RULES.md`를 커밋한다
4. Drive에도 같은 이름으로 올린다
5. 제미니·클로드에게 “규칙 문서 갱신됨”만 알린다
