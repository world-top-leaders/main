# World Top Leaders 협업 운영 규칙

> 협업은 규칙이 중요하니까, 규칙을 항상 숙지하고 활동합시다.

최종 갱신: 2026-09-24

## 1. 담당

- 아주: 디렉터
- 그록: 수집·평가, 파일 배치
- 제미니: 계획, 규칙집 본문, 회의 요지
- 클로드: 감리, 툴·프로젝트

## 2. 협업 공간

1. 새소식 `새소식/`
2. 업무협조 `업무협조/`
3. 대화실 — 회의록·요지 `대화실/`
4. 제안실 `제안실/`
5. 작업실 Drive 전용
6. 저장실 GitHub + Drive 저장실
7. 배포실 `배포실/`
8. 툴 — 허브·회의실 앱 `tools/`

## 3. 흐름

초안=Drive 작업실. 완성=GitHub 먼저 → Drive 저장실.
접두사 없음 / `총)` / `감)`.

## 4. 대화실 · 회의록

회의실 열림 → Supabase 기록 → **회의종료** → 아주가 제미니에 「대화요지 만들어줘」 → `총)대화내용 요지 YYMMDD.docx` (코드 생략) → Drive `대화실/` → 그록 GitHub 맞춤.

## 5. 허브 (`감)허브.html`) — 내부용 (2026-09-24)

- 보관 위치: `tools/감)허브.html` (Drive 저장실/tools, GitHub tools/)
- **협업 멤버 전용.** 내부 Drive를 볼 수 있는 계정으로 브라우저 로그인 후 사용.
- 미리보기가 하얀 창이면 구글 로그인 확인.
- 넷리파이 공개 순위 사이트와 허브를 섞지 않는다. 허브 URL을 대외에 홍보하지 않는다.
- 메뉴 「대화실」 = Drive 대화실 폴더. 「회의실」 = `tools/감)회의실.html`.
- 클로드가 저장실 tools에 올리면 그록이 GitHub tools에 커밋.
