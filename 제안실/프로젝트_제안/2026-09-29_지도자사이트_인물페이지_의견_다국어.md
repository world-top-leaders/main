# 과제: 세계 지도자 사이트 — 인물 페이지 · 고객 의견 · 다국어

작성: 그록 / 아주 외부 지시 · 2026-09-29
상태: 계획·감리 먼저. 구현은 합의 후.
대상: 공개 사이트 https://world-top-leaders.netlify.app (`index.html`)
관련 규칙: 공개 순위 사이트와 내부 허브(`tools/감)허브.html`)를 섞지 않는다.

## 한 줄

메인 표에서 지도자를 누르면 그 사람 페이지가 나오고,
메인 표 행·표 아래·개별 페이지에서 고객이 의견을 남길 수 있게 하며,
사이트는 영어/한국어가 통하게 한다.

## 기능

### 1. 이름 → 위키 개인 페이지
- 표의 이름(예: Sam Altman)을 누르면 위키 **개인 문서**로 이동.
- 영어 모드 = 영어 위키. 한국어 모드 = 한국어 위키.
- 회사 페이지나 동명이인으로 가지 않음.

### 2. 지도자 개별 페이지
- 예: Sam Altman 전용 페이지.
- 우리 점수·소속·역할 + 위키 링크.
- 순위·점수는 고객이 수정하지 못함.

### 3. 고객 의견 (셀처럼 보이게, 저장됨)
의견을 두는 곳은 세 군데, **데이터는 하나**.

1. 메인 테이블 각 행 — 그 줄 지도자에 대한 짧은 의견(또는 개수 미리보기). 긴 글은 개별 페이지로.
2. 메인 테이블 아래 — 사이트 전체 의견.
3. 개별 페이지 아래 — 그 사람 의견 전체. 메인 행에 쓴 글과 같은 저장소.

저장 키: 지도자 이름 + 시각 + 작성자 + 내용.
저장 후보: 구글시트(엑셀처럼 직접 편집) / 제출 폼으로 시트에 한 줄씩 쌓기.
**아직 미정 — 합의 필요.**

### 4. 언어 호환
- EN / 한국어 전환.
- 점수·순위는 공통. 안내문·역할·노트·위키 링크만 언어에 맞게.

## 먼저 정할 것

| 항목 | 선택 |
|---|---|
| 개별 페이지·의견란 위치 | 공개 사이트 / 내부 허브만 / 공개는 읽기, 쓰기는 제한 |
| 의견 저장 | 구글시트 직접 편집 / 제출 폼으로 시트에 쌓기 |
| 누가 글을 쓰나 | 아무나 / 링크 있는 사람만 / 검수 후 공개 |
| 1차 언어 | 영어 기본 + 한국어 / 둘 다 동등 |

## 역할

- 제미니: 계획. 페이지 구조, 시트 칸 설계, 언어 전환.
- 클로드: 감리. 스팸·권한·허브/공개 분리.
- 그록: 합의 후 `index.html`·인물 페이지 배치, GitHub 먼저 커밋.
- 아주: 공개 여부 최종 결정 (돌아와서).

## 하지 말 것

- 고객이 순위·점수를 직접 고치게 하지 않음.
- 내부 허브 URL을 공개 사이트에 섞지 않음.
- 저장 방식 정하기 전에 가짜 입력칸만 올려 두지 않음.

## 완료 기준

- 이름 클릭 → 위키 개인 문서
- 인물별 URL이 있음
- 메인 테이블 행에도 의견 셀이 있음
- 의견이 새로고침 후에도 남아 있음 (메인 행 ↔ 개별 페이지 동기화)
- EN / 한국어 전환
- GitHub `world-top-leaders/main`에 먼저 올라감
