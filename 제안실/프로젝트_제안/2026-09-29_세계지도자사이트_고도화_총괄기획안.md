## 1. 추진 배경 및 목표
1. **배경:** 아주의 방향 지시와 그록의 1차 제안(2026-09-29_지도자사이트_인물페이지_의견_다국어.md)을 구체화하여 단순 순위 열람을 넘어 데이터 분석과 대중 참여가 공존하는 플랫폼으로 전환.
2. **목표:**
   - 50인 지도자별 고유 프로필과 다각도 평가 지표를 제공하는 **개별 인물 페이지** 구축.
   - 데이터 사이트 정체성을 유지하면서 정돈된 참여를 유도하는 **엑셀형 고객 의견 시트(1줄 말줄임 ↔ 클릭 시 확장, 좋아요, 대댓글)** 구현.
   - 한국어와 영어를 원활하게 넘나는 **완전 다국어(i18n) 시스템** 안착.

## 2. 3대 핵심 상세 기획
### ① 인물 상세 페이지 (leader.html)
- **프로필 헤더:** 고화질 프로필 사진, 영문/현지어 성명, 현재 소속/직책, 글로벌 순위 배지.
- **상세 인적사항 그리드:** 출생(일시·장소), 성별, 국적, 학력, 주요 경력, 직업 및 전문분야, 추정 순자산, 대표 업적.
- **WTL 평가 시각화:** 종합 평균 점수 및 4대 평가 축(연구, 사업, AGI, 재산) 레이더/바 차트.
- **다국어 링크 연동:** 언어 모드(EN/KO)에 따라 영문 위키백과와 한국어 위키백과로 자동 분기 매핑, 공식 SNS/웹사이트 연결.
### ② 엑셀형 고객 의견 시트 (단일 저장소 연동)
- **표시 영역 (3-Point View, Single-Source Data):**
  1. 메인 테이블 각 행: 지도자별 최신 의견 1줄 미리보기 및 댓글 수/공감수 배지.
  2. 메인 테이블 하단: 사이트 종합 의견을 남기는 전체 엑셀형 시트.
  3. 인물 상세 페이지 하단: 해당 지도자에 특화된 의견 목록 및 작성 시트.
- **UI/UX 인터랙션 규칙:**
  - **기본 상태:** 엑셀 셀처럼 텍스트를 1줄로 제한하고 말줄임(...) 처리하여 높은 정보 밀도 유지.
  - **클릭 시 동작 (아코디언 방식):** 행을 클릭하면 아래로 부드럽게 펼쳐지며 **전체 본문 + 좋아요(퇴) 버튼 + 대댓글(Thread) 작성창** 노출.
  - **정렬 필터:** 최신순, 공감 많은 순, 댓글 많은 순.
- **저장소:** 구글 드라이브 구비 시트(WTL_고객의견_관리시트) 및 Supabase comments 테이블 연동.
### ③ 다국어(i18n) 아키텍처
- **단일 소스 기반 전환:** 페이지 복제 없이, 상단 토글 스위치([KO] | [EN]) 클릭 시 locales.json 사전 데이터를 통해 라벨과 링크 즉시 전환.
- **다국어 분기 기준:**
  - **공통 불변:** 점수, 순위, 자산 수치, 프로필 사진 URL, SNS 링크.
  - **언어 맞춤:** UI 텍스트(컬럼명, 안내문, 버튼), 직책 설명, 위키백과 타깃 URL.
- **의견 다국어 배려:** 의견 작성 언어 코드(ko/en)를 기록하고, 외국어 의견에는 [퇌 번역] 간이 번역 버튼 제공.
