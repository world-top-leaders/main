1. **배경:** 아주의 방향 지시와 그록의 1차 제안(2026-09-29_지도자사이트_인물페이지_의견_다국어.md)을 구체화하여 단순 순위 열람을 넘어 데이터 분석과 대중 참여가 공존하는 플랫폼으로 전환.
2. **목표:**
   - 50인 지도자별 고유 프로필과 다각도 평가 지표를 제공하는 **개별 인물 페이지** 구축.
   - 데이터 사이트 정체성을 유지하면서 정돈된 참여를 유도하는 **엑셀형 고객 의견 시트(1줄 말줄임 ↔ 클릭 시 확장, 좋아요, 대댓글)** 구현.
   - 한국어와 영어를 원활하게 넘나는 **완전 다국어(i18n) 시스템** 안착.

## 2. 3대 핵심 상세 기획
### ① 인물 상세 페이지 (leader.html)
- **프로필 헤더:** 고화질 프로필 사진(없으면 영문 이니셜 SVG), 영문/현지어 성명, 현재 소속/직책, 글로벌 순위 배지.
- **상세 인적사항 그리드:** 출생(일시·장소), 성별, 국적, 학력, 주요 경력, 직업 및 전문분야, 추정 순자산, 대표 업적.
- **WTL 평가 시각화:** 종합 평균 점수 및 4대 평가 축(연구, 사업, AGI, 재산) 레이더/바 차트.
- **다국어 링크 연동:** 언어 모드(EN/KO)에 따라 위키 타깃. `wiki_ko` 없으면 `wiki_en` 폴백.
### ② 엑셀형 고객 의견 시트 (단일 저장소 연동)
- **표시 영역 (3-Point View, Single-Source Data):**
  1. 메인 테이블 각 행: 지도자별 최신 의견 1줄 미리보기 및 댓글 수/공감수 배지.
  2. 메인 테이블 하단: 사이트 종합 의견을 남기는 전체 엑셀형 시트.
  3. 인물 상세 페이지 하단: 해당 지도자에 특화된 의견 목록 및 작성 시트.
- **UI/UX:** 1줄 말줄임 → 클릭 시 본문 + 좋아요 + 대댓글. 정렬: 최신 / 공감 / 댓글.
- **저장 컬럼 8개:** comment_id, timestamp, leader_slug, author, language, content, likes, parent_id
- **저장소:** Supabase comments 주 저장 + Drive `WTL_고객의견_관리시트` 백업.
### ③ 다국어(i18n)
- 상단 [KO] | [EN]. 사전: `data/locales.json`
- 공통 불변: 점수, 순위, 자산, 사진 경로, SNS, slug
- 언어 맞춤: UI 라벨, 직책, 위키 URL (`wiki_ko` 없으면 `wiki_en`)
