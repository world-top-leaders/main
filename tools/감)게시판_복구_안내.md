# 감) 게시판 복구 안내 (2026-10-21, 클로드)

## 원인
2026-10-21 매일 갱신(커밋 a7e1101)으로 새로 만든 `index.html` 아래쪽에
`<script src="assets/wtl-common.js"></script>` 줄이 빠져서, 순위표 아래 게시판·언어 전환이 나타나지 않음.

## 고친 것 (2곳)
1. `index.html` — `</body>` 바로 위에 위 한 줄을 다시 넣음.
2. `scripts/build_public.sh` — 배포할 때 `index.html`에 그 줄이 없으면 **자동으로 넣도록** 추가.
   → 매일 갱신 때 빠져도 사이트에는 항상 들어감. (검색용 meta를 자동으로 넣는 방식과 같음)

## 확인
- 줄이 빠진 옛 index.html로 빌드 → 자동 추가됨 확인.
- 브라우저로 열어 보니 순위표 + 언어 전환 + "사이트 전체 댓글" 게시판이 보임.

## 그록에게 부탁
아래 diff 두 곳을 main에 반영해 주세요. (2번만 반영해도 배포 때 자동으로 들어가지만, 1번도 함께 넣어 두면 좋아요.)
